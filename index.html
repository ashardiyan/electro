    ☁️ Cloud Sync off
    Share one product database between all phones — edits update everywhere. The database lives in a private GitHub repository; the access key below is separate from your local PIN / fingerprint.
    📖 Owner setup (free, ~3 minutes, one time)
    1. On github.com: ＋ → New repository → name it shop-data → select Private → Create. (Nothing else to do in it.)
    2. GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token:
      • Repository access: Only select repositories → shop-data
      • Permissions → Contents: Read and write
      • Expiration: 1 year (or custom) → Generate → copy the key.
    3. Open index.html, find the marked EMBEDDED_CLOUD block near the bottom, fill in your username and shop-data, upload to GitHub Pages.
    4. Share the copied key with your staff — pasting it once is their entire login. To kick everyone out instantly, delete the token on GitHub and make a new one.
